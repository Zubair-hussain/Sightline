Set up

Connect your AI apps.

Sightline speaks MCP (Model Context Protocol), so AI assistants can audit websites for you.

  1. Install the desktop app and open Settings → Connect AI apps.
  2. Copy the snippet into your AI app: Cursor (Settings → MCP) or VS Code (.vscode/mcp.json).
  3. Ask: “Audit example.com and tell me what to fix first” or “Check example.com for memory leaks”.
{ "mcpServers": { "sightline": { "command": "/Applications/Sightline.app/Contents/MacOS/Sightline", "args": ["--mcp"] } } }

Questions.

Is Sightline free?

Yes. The desktop app is free, and the web version is free with a fair-use limit per hour.

Do I need to be a developer?

No. Type a website address and press Audit. Every problem comes with a plain explanation and a suggested fix. Each audit has a “What does it check?” button.

Why do some audits need the desktop app?

Performance, iPhone & iPad and memory-leak tests have to open your page in a real browser and use it for a while. The desktop app includes that browser engine; a website cannot safely do this for you.

Does it work on a MacBook?

Yes. The macOS download is a universal app that runs natively on Apple Silicon (M1, M2, M3, M4) and Intel Macs with macOS 11 or later.

What happens to the sites I audit?

The desktop app runs entirely on your computer. The web version fetches the page from our server to audit it and does not store your reports — history is kept in your own browser.

Can I audit pages behind a login or on localhost?

Use the desktop app for local and staging sites. The web version only audits public websites.
